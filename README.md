# Planets Fact Site

Welcome to the **Planets Fact Site**!

This project is a simple website that presents interesting facts about the planets in our solar system. It was created as my very first website project, serving as a learning experience and a showcase of my initial steps into web development.

## About

The Planets Fact Site is designed to display information and fun facts about each of the planets in our solar system. The site features basic web technologies and demonstrates my early understanding of HTML, CSS, and some JavaScript.

## Why This Exists

> **Note:** This was my first ever website. I’ve kept it here as a milestone, to track my progress as a developer and to remind myself of how far I’ve come. While it may be simple, it represents the foundation of my journey in web development.

## Challenge

This website was developed as a coding challenge from [Frontend Mentor](https://www.frontendmentor.io/). The challenge provided the design and requirements, and I built this site to improve my frontend skills and gain practical experience.

## Features

- Overview of each planet in the solar system
- Simple, clean design
- Easy navigation

## Getting Started

To view the website locally:

1. Clone this repository:
    ```bash
    git clone https://github.com/kayan2004/planets-fact-site.git
    ```
2. Open the `index.html` file in your web browser.

No additional setup is required.
